---
description: Show the design tool catalog without running anything
argument-hint: "[look|feel|fix|judge|lookup|all]"
---

Show the `design-tools` catalog for: **$ARGUMENTS** (default: all groups).

Read `references/catalog.md` and print the matching groups as a table: tool · vendor · writes or
reports · what it is for · when not to reach for it. Add the relevant entries from
`references/collisions.md` for any group that contains a contested tool.

Change nothing. This command answers "what have I got", not "do something".
