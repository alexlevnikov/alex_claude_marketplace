# tponscr-debug — design-awwwards

Один арт-директор для выразительных веб-страниц по принципам проектов уровня Awwwards.

**Как работает.** Основной скилл awwwards сам ведёт исследование, типографику, палитру, композицию и motion для указанной поверхности.

**Пустой вызов.** Покажи этот краткий разбор, примеры ниже и при необходимости полный каталог. Не запускай скилл и не меняй проект без конкретной задачи.

**Явный вызов.** В Codex выберите навык через `$`; в Claude Code используйте команду `/`. Для обзора: `$design-awwwards:overview` или `/design-awwwards:overview`. Упоминание `@` прикладывает плагин к контексту и не заменяет выбор навыка.

**Примеры задач:**

- `/design-awwwards:awwwards` или `$design-awwwards:awwwards` — создать смелое визуальное направление для лендинга.

**Ограничения.** Встроенные справочники — статические, это не живой поиск по Awwwards. Для новой большой поверхности можно использовать общий design-pipeline.

## Все отдельные скиллы

Каждая строка указывает прямой вызов и задачу, для которой подходит скилл. Для запуска добавьте цель или файл после команды/навыка.

| --- | --- | --- | --- |
