# calmtiger86 — design-calm-design

Полный процесс создания спокойного премиального интерфейса с DESIGN.md, самокритикой и финальными проверками.

**Как работает.** Один master выбирает режим interview, generate, upgrade, reference-match или multi-variant и подходящий выходной формат.

**Пустой вызов.** Покажи этот краткий разбор, примеры ниже и при необходимости полный каталог. Не запускай скилл и не меняй проект без конкретной задачи.

**Явный вызов.** В Codex выберите навык через `$`; в Claude Code используйте команду `/`. Для обзора: `$design-calm-design:overview` или `/design-calm-design:overview`. Упоминание `@` прикладывает плагин к контексту и не заменяет выбор навыка.

**Примеры задач:**

- `/design-calm-design:calm-design` или `$design-calm-design:calm-design` — обновить существующий экран в спокойном стиле.
- `/design-calm-design:calm-design` или `$design-calm-design:calm-design` — создать несколько вариантов концепции.

**Ограничения.** Исходный процесс ориентирован на корейский язык; явно попросите другой язык при необходимости. Визуальная проверка зависит от доступных инструментов.
