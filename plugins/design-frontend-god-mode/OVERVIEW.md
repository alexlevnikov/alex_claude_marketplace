# Shawnchee — design-frontend-god-mode

Широкий frontend master для создания, переработки и полировки UI с единой дизайн-дисциплиной.

**Как работает.** Один скилл анализирует проект и DESIGN.md, выбирает визуальное направление, обращается к встроенным справочникам и проводит preflight.

**Пустой вызов.** Покажи этот краткий разбор, примеры ниже и при необходимости полный каталог. Не запускай скилл и не меняй проект без конкретной задачи.

**Явный вызов.** В Codex выберите навык через `$`; в Claude Code используйте команду `/`. Для обзора: `$design-frontend-god-mode:overview` или `/design-frontend-god-mode:overview`. Упоминание `@` прикладывает плагин к контексту и не заменяет выбор навыка.

**Примеры задач:**

- `/design-frontend-god-mode:frontend-god-mode` или `$design-frontend-god-mode:frontend-god-mode` — переработать интерфейс приложения целиком.

**Ограничения.** Может создать или обновить корневой DESIGN.md; при отсутствующих зависимостях предлагает настройку. Выбирайте его осознанно для широкой задачи.
