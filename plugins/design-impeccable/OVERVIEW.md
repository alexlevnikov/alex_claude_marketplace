# impeccable by pbakaus — design-impeccable

Один дизайн-директор для создания, критики, полировки и визуальной итерации интерфейса.

**Как работает.** У одного основного скилла есть внутренние режимы shape, audit, polish, live и generate. Без цели он показывает контекстное меню, не выполняя режим автоматически.

**Пустой вызов.** Покажи этот краткий разбор, примеры ниже и при необходимости полный каталог. Не запускай скилл и не меняй проект без конкретной задачи.

**Явный вызов.** В Codex выберите навык через `$`; в Claude Code используйте команду `/`. Для обзора: `$design-impeccable:overview` или `/design-impeccable:overview`. Упоминание `@` прикладывает плагин к контексту и не заменяет выбор навыка.

**Примеры задач:**

- `/design-impeccable:impeccable` или `$design-impeccable:impeccable` — провести audit существующей страницы.
- `/design-impeccable:impeccable` или `$design-impeccable:impeccable` — запустить polish готового экрана.

**Ограничения.** Локальный launcher может скачать бинарник при первом использовании. Для полноценной работы нужен контекст проекта.
