# LottieFiles — design-lottie

Принципы проектирования UI-motion от LottieFiles: тайминг, easing, хореография и выбор способа реализации.

**Как работает.** Один основной скилл motion-design проектирует движение с нуля и применим к CSS, Motion, GSAP, Lottie и пружинам.

**Пустой вызов.** Покажи этот краткий разбор, примеры ниже и при необходимости полный каталог. Не запускай скилл и не меняй проект без конкретной задачи.

**Явный вызов.** В Codex выберите навык через `$`; в Claude Code используйте команду `/`. Для обзора: `$design-lottie:overview` или `/design-lottie:overview`. Упоминание `@` прикладывает плагин к контексту и не заменяет выбор навыка.

**Примеры задач:**

- `/design-lottie:motion-design` или `$design-lottie:motion-design` — спланировать анимацию перехода между состояниями.

**Ограничения.** Для встраивания готовой Lottie-анимации и управления playback используйте iart:lottie-animation.
