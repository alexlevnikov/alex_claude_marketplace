# Motion.dev skill — design-motion-dev

Паттерны Motion.dev/Framer Motion для входов, скролла, жестов, микровзаимодействий и layout-переходов.

**Как работает.** Один master motion-dev-animations уточняет задачу, планирует эффект, реализует и проверяет его по встроенным примерам и справочникам.

**Пустой вызов.** Покажи этот краткий разбор, примеры ниже и при необходимости полный каталог. Не запускай скилл и не меняй проект без конкретной задачи.

**Явный вызов.** В Codex выберите навык через `$`; в Claude Code используйте команду `/`. Для обзора: `$design-motion-dev:overview` или `/design-motion-dev:overview`. Упоминание `@` прикладывает плагин к контексту и не заменяет выбор навыка.

**Примеры задач:**

- `/design-motion-dev:motion-dev-animations` или `$design-motion-dev:motion-dev-animations` — добавить draggable carousel в React.
- `/design-motion-dev:motion-dev-animations` или `$design-motion-dev:motion-dev-animations` — сделать layout transition.

**Ограничения.** Предназначен для проектов на Motion.dev/Framer Motion, а не произвольных анимационных стеков.
