# frhscopex design-skill-os — design-skill-os

Справочник принципов дизайна из десяти книг: исследование, типографика, цвет, композиция, брендинг, сторителлинг и процесс.

**Как работает.** Один read-only скилл design отвечает на вопрос и обосновывает дизайн-решение; файлы и интерфейс не меняет.

**Пустой вызов.** Покажи этот краткий разбор, примеры ниже и при необходимости полный каталог. Не запускай скилл и не меняй проект без конкретной задачи.

**Явный вызов.** В Codex выберите навык через `$`; в Claude Code используйте команду `/`. Для обзора: `$design-skill-os:overview` или `/design-skill-os:overview`. Упоминание `@` прикладывает плагин к контексту и не заменяет выбор навыка.

**Примеры задач:**

- `/design-skill-os:design` или `$design-skill-os:design` — обосновать типографическую иерархию.
- `/design-skill-os:design` или `$design-skill-os:design` — сравнить две цветовые стратегии.

**Ограничения.** Это поиск и объяснение принципов, без реализации кода.
